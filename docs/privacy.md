# Privacy Policy

Notification Saver stores captured notification history locally on your Android device so you can review it later.

## What The App Stores

- App label and package name
- Notification timestamps
- Title, body, expanded text, text lines, and content-distinct revisions when available
- Conversation name, sender name, and extracted MessagingStyle text messages when available
- User-managed metadata such as category, tags, theme preference, exclusions, and pinned conversations
- Local operational counters, logs, and crash reports

## What The App Does Not Do

- It does not request internet access or upload notification contents to a hosted backend.
- It does not copy notification images or attachments into the archive.
- It does not include notification contents in diagnostics exports.
- It does not require a cloud account.

## User Controls

- Create password-encrypted backups, import them in merge or replace mode, or export readable JSON
- Export diagnostics bundles without notification content
- Delete individual notifications
- Delete filtered notification scopes
- Hide list and recents previews, block screenshots, and require device authentication
- Clear logs and crash reports independently
- Clear all saved app data from the app UI

## Platform Limitations

Android controls which notifications are delivered to a listener. The system or source app may redact sensitive fields, withhold work-profile or OTP content, or remove a notification before the listener can reconnect. Notification Saver cannot reconstruct events it never received.
