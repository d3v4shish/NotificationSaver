# Screenshot Capture Checklist

1. Install the debug build on an emulator.
2. Launch the app and dismiss onboarding once.
3. Open `Settings` and tap `Load demo data`.
4. Capture `Inbox`, `Chats`, notification detail, conversation detail, and `Settings` at phone size.
5. Repeat the Inbox and Chats captures at a tablet width to show the adaptive two-pane layout.
6. Save curated screenshots under `docs/assets/screenshots/`.
7. Reuse those PNGs in `README.md` and the landing page export.
