# Screenshot Capture Checklist

1. Install the debug build on an emulator.
2. Launch the app and dismiss onboarding once.
3. Open `Settings` and tap `Load demo data`.
4. Return to `Timeline`, `Threads`, and `Priority`.
5. Capture curated screenshots and save them under `docs/assets/screenshots/`.
6. Reuse those PNGs in `README.md` and the landing page export.
