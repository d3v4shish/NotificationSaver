# Security Policy

## Supported Version

The latest tagged release is the only supported security target.

## Reporting A Vulnerability

Please do not open a public issue for a security-sensitive report.

Until a dedicated private mailbox exists, report vulnerabilities directly to the repository owner through GitHub private security reporting if enabled, or by private contact outside public issues.

Include:

- Affected version
- Reproduction steps
- Expected impact
- Whether notification content exposure is involved

## Privacy Notes

- Notification contents are stored locally on-device.
- The app does not intentionally send notification contents to remote services.
- Diagnostics export is user-initiated and intentionally excludes notification payload contents.
