# Code Of Conduct

This project adopts the Contributor Covenant Code of Conduct.

## Our Standards

- Be respectful and direct.
- Assume good intent, but be precise when discussing technical concerns.
- Focus criticism on code and behavior, not people.
- Respect user privacy and security concerns as first-class product requirements.

## Unacceptable Behavior

- Harassment or personal attacks
- Doxxing or disclosure of private user data
- Bad-faith arguments or repeated disruption
- Publishing private notification payloads in issues, PRs, or screenshots

## Enforcement

Project maintainers may remove content, close discussions, or block contributors who violate this code.
